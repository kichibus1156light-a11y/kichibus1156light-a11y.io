コロニー落とし 3D / スマホ版
================================

このフォルダの index.html をスマートフォンのブラウザで開いてください。

推奨:
- Safari / Chrome の最新版
- 横向き表示
- 初回起動時はネット接続あり（Three.js 本体を読み込みます）
- Web公開した場合は Service Worker が有効になり、2回目以降はキャッシュを利用します
- 「ホーム画面に追加」すると、アプリ風の全画面起動ができます

今回のスマホ改良:
- 固定デバッグ時刻を解除
- モバイル時 30fps に描画を制限して発熱・バッテリー消費を軽減
- モバイルのピクセル比を上限 1.25 に制限
- 星・パーティクル・ジオメトリを低負荷化
- 画面のセーフエリア（ノッチ/ホームバー）対応
- UIを横スクロール可能なタッチ操作へ調整
- タブを離れたときに再生を停止
- WebGLコンテキスト喪失時の復帰処理を追加
- Font Awesome をローカル配置
- PWA manifest / Service Worker を追加

注意:
完全な「初回から完全オフライン」の配布には Three.js 本体のローカル同梱が必要ですが、
この実行環境では外部CDNからライブラリを取得できなかったため、Three.jsは既存のCDN参照を維持しています。
Web公開後に一度オンラインで開けば、Service Worker のキャッシュ対象になります。
